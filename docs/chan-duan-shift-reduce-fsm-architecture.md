# 缠论线段移进-规约状态机（Shift-Reduce FSM）架构规范

## 1. 背景与历史问题

在原有的线段生成逻辑中存在以下根本缺陷：
1. **过程式命令循环与游标污染**：原 `duan.ts` 采用双层循环和多标志位维护（`flag / inSpecialSegment / isGapFenxing` 等），导致特征序列在跨多笔推进时状态容易错乱。
2. **特征序列缺口比对错位**：原本在比较向上段的特征序列（向下笔元素）时，错误地跨越了中间的上涨笔，拿波谷和波峰直接比价格，导致在正常上涨主升浪中误判出“虚假缺口”，进而在未创新高前提前阻断线段。
3. **生硬限制“线段必须 $\ge 3$ 笔”**：曾有提交（`14fe0425`）试图机械阻止任何 $\le 2$ 笔的线段结束。然而在真实走势中（如 2024-09-18 的 2689.70 到 2024-10-08 的 3674.41 单笔暴涨），该极值后走出了标准的 9 笔下跌段（下探至 3040.69）。根据缠论第 71 课与第 78 课**“线段只能被线段破坏”**的最高公理，一个已经确认的完整反向线段，必须能够终结前一个极值点（即使前一个极值只有 1 笔）。原先的硬编码限制导致 3674.41 大顶无法封顶，线段被错误拖拽至 2025年3月的 3439.05，进而导致随后的 3040.69 与 4034.08 全部切错。

## 2. 核心架构：移进-规约状态机（Shift-Reduce FSM）

基于缠论第 65、67、71、78、81 课，建立纯净的下推式（Shift-Reduce）线段归约状态机。

### 2.1 状态定义与要素隔离（Lesson 71 隔离律）

对于一个进行中的线段（初始方向 `originalDir`）：
- **转折前笔栈（first）**：线段极值点之前的最后一根特征元素。
  - 向上段：向下的笔（极值前一笔向下，极值点为其后的向上笔端点）；
  - 向下段：向上的笔。
- **转折后笔栈（secondSeq）**：线段极值点之后的同向笔集合。
  - 向上段：极值点之后的向下笔；
  - 向下段：极值点之后的向上笔。
- **Lesson 71 隔离律**：转折前元素 `first` 与转折后第一元素 `secondSeq[0]` **绝对禁止发生包含合并**。二者属于不同的时序空间，若合并将直接破坏极值点的几何边界。

### 2.2 包含合并规则（Lesson 78 包含律）

- 转折后序列 `secondSeq` 内部的包含合并，其合并方向**必须严格与原线段方向相同**（`originalDir`）。
  - 向上段中，`secondSeq` 元素采用向上包含（高高取高，低高取高）；
  - 向下段中，`secondSeq` 元素采用向下包含（低低取低，高低取低）。

### 2.3 第一种情况 vs 第二种情况（Lesson 67 判据）

1. **第一种情况（无缺口）**：
   - `first` 与 `secondSeq[0]` 之间存在价格重叠（无缺口）；
   - 在 `secondSeq` 中只要出现**方向一致的分型**（向上段出顶分型，向下段出底分型），立即确认线段结束，极值点封盘；
   - 结束点为原线段极值点 `currentPeak`。

2. **第二种情况（有缺口）**：
   - `first` 与 `secondSeq[0]` 之间无价格重叠（存在跳空缺口）；
   - 根据第 67 课，不能仅仅凭 `secondSeq` 出现分型就确认线段结束；必须由**反向特征序列（即破坏该缺口方向的序列）再次形成分型**，或者反向走势走出完整线段破坏，方能确认线段结束；
   - 若未确认，且随后走势突破了 `currentPeak`，则原线段继续延伸，更新 `currentPeak`。

### 2.4 反向线段破坏（Lesson 71 / 78 公理）

当 `first === null`（线段只有 1 笔暴涨/暴跌便见顶底，如 3674.41）：
- 检查极值点之后的走势是否构成了完整的**反向有效线段**（$\ge 3$ 笔，且中途未突破该极值点）；
- 若反向线段完成确认（形成合规的段端点），则由反向线段确认该极值点合法封顶/封底；
- 该规则彻底解决了暴力单笔单边行情（2024年10月8日 3674.41）的大顶封盘判定。
