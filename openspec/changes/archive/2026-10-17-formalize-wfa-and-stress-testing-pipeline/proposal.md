# Proposal: 规范化量化策略防过拟合验证、滚动前向（WFA）与极端压力测试工程流水线

## 1. 背景与核心痛点（Context & Problem Statement）

在量化交易系统（Mist）开发与回测中，直接基于全量历史时序（如 1990 年至今上证指数）进行全局回测或参数优化，存在极大的**参数过拟合与虚假因果陷阱**。同时，朴素的“手工挑选平稳段开发、剔除极值段测验”方案也存在三大致命缺陷：

1. **事后已知的前视偏差（Lookahead / Hindsight Bias）**：
   实盘中极值的发生事前不可知（Ex-ante vs Ex-post）。人工在历史数据中“挑选平稳段”注入了上帝视角；一旦极值来临，策略往往在极值初期就大幅反向抄底或死扛导致巨额穿仓；同时，在测试集未通过时反复调参，会诱发隐性的第二类过拟合（Data Snooping）。
2. **截断厚尾的“低波温室假象”（Distribution Shift）**：
   A 股具有强烈的尖峰厚尾与波动率聚集特征。若人为剔除极端波动，策略模型在低波平庸样本上会学到“过高杠杆、过宽止损、死扛必胜”的毒性参数，实盘一旦遭遇中等波动即遭受毁灭性打击。
3. **“信号（Signal）”与“动作（Action）”混淆引发的架构割裂**：
   - 决策树（`DecisionFlowEvaluator`）是纯客观的无状态分析器，只有行情结构信号的概念，根本没有账户持仓状态；
   - 真实的持仓平仓必须依赖账户持仓快照（持仓股数、买入均价、浮动盈亏）；
   - 若把买入风控放在决策树顶层门禁，而把平仓风控放在持仓状态机，会导致**“非对称依赖”与“双头指挥”**，平仓动作散落在 `onSignal` 与 `onBar` 两处，破坏单一事实来源。
4. **A 股历史时序的制度异质性（Institutional Breaks）**：
   1990-1996 年无涨跌幅限制、实行 T+0、标的仅有“老八股”等极少数量，属于必须剔除的**“有毒数据”**；而 2015 股灾、2024 微盘挤兑具有“一字连续跌停无法卖出、千股停牌”的微观流动性断层，若回测引擎缺乏真实制度摩擦约束，会产生“跌停板从容逃顶”的虚假回测幻象。

## 2. 目标与演进范围（Scope & Goals）

本提案旨在将零散、主观的手工切片回测改造为一套公理化、工程化、严格因果保真的**四层防过拟合与极端压力测试流水线**。

### 2.1 核心目标（四步演进）

1. **第一步：Alpha 形态信号与统一动作裁决器彻底正交解耦（Alpha-Action Orthogonal Decoupling）**：
   - **上游决策树彻底保洁**：`StrategyEvaluationKernel` 专职作为纯形态与动量雷达，只输出客观的候选信号（`BUY` / `SELL`），不掺杂大盘风控门禁，不感知账户持仓状态；
   - **下游统一动作与风控裁决器（Execution & Risk Arbiter）**：在后续执行流程（`BrokerExecutionSink`）中收拢所有交易动作与风控决策，实现绝对对称的单向依赖管理：
     - **管买入（开仓风控）**：收到 `BUY` 候选信号时，结合大盘体制裁决；大盘处于系统性雪崩（`SYSTEMIC_CRUNCH`）时行使系统级一票否决权（Veto），安全时方才生成买入委托；
     - **管持仓（平仓风控）**：持有仓位时，按照清晰的三级优先级统一发出 `SELL ORDER` 平仓动作：
       `[优先级 1] 系统生存级 (大盘雪崩清仓) > [优先级 2] 持仓风控级 (个股硬止损) > [优先级 3] 策略逻辑级 (形态二卖/三卖)`；
   - **持仓状态机（`PositionStateMachine`）回归纯记账**：拔除其内部在 `onBar` 偷偷平仓的逻辑，平仓动作 100% 收敛由裁决器下达。
2. **第二步：实现自动化滚动步进前向分析流水线（Walk-Forward Analysis Pipeline, WFA）**：
   - 构建 `WalkForwardOrchestrator`，支持固定滑窗滚动（Rolling WFA）与起点锚定扩张（Anchored WFA）；
   - 自动划分 Fold，利用 `HistoricalBarSource` 自动预热并推进游标；
   - 自动缝合所有样本外（OOS）测试区间的连续净值与交易明细，生成真实前向跟踪曲线，评估参数稳定性指数（PSI）与衰减率。
3. **第三步：构建 A 股五大历史极端事件压力测试套件（Stress Testing Suite & Benchmarks）**：
   - 在数据加载入口建立 `DataSanitizationGuard`，物理截断并坚决剔除 1996 年底前的有毒数据，以 2005 年 5 月股改作为现代回测基准；
   - 封装五大标准历史压力沙盒（2015 杠杆踩踏、2016 熔断、2018 阴跌磨损、2024 微盘挤兑、2024 924 脉冲）；
   - 压力测试套件独立于常规回测，专注评估生存边界。
4. **第四步：基于 Rust Polars SIMD 底座扩充纯数学极端压力指标库**：
   - 严格在 `libs/indicators/src/performance` 内基于 `nodejs-polars` 扩展向量化压力算子：在险价值 VaR (95%/99%)、条件在险价值 CVaR、最大回撤持续期（Underwater Duration）、跌停顺延流动性延迟惩罚（Liquidity Delay Loss）及样本外过拟合衰减比率（Overfitting Ratio）。

### 2.2 非目标（Out of Scope）

- **Zero Code Modification in Planning**：本阶段为纯方案规划与规格落盘，绝不修改业务生产代码；
- 不破坏现有单次回测（Single Backtest Run）的 RPC 接口与契约，所有高阶编排以组合（Suite）模式向上扩展；
- 不在指标库（`libs/indicators`）引入任何外部 I/O、数据库或 Node.js 框架依赖，坚守 Rust SIMD 纯数学边界。

## 3. 关联影响与系统价值

- **`libs/strategy`**：
  - 决策树退回纯形态雷达，彻底解脱宏观风控负担；
  - 执行层沉淀标准的动作与风控裁决器，彻底拔除双头平仓；
- **`apps/backtest`**：从单次机械回测升级为具备工业级 WFA 前向验证与一键黑天鹅压力体检的专业回测系统；
- **`libs/indicators`**：从基础的收益回撤指标扩展出高阶量化风险与压力测试数学指标体系；
- **投资决策安全性**：彻底杜绝“温室低波拟合”与“跌停逃顶回测幻象”，真正筛选出具备跨周期生命力的实战策略。
