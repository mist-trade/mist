# Design: Wave 3 Technical Debt Cleanup, Validation Hardening & Schema/Query Optimization

## Key Decisions
1. **Dead `exitRatio` Removal**: Wave 1/2 deprecated partial-exit `PositionStateMachine.exitRatio`. Removing `exitRatio`, `calculateExitQuantity`, `getExitRatio`, and `PositionStateMachineOptions` leaves full-position accounting clean with zero dead config branches.
2. **Idempotent Day-Rollover Settlement in `SimulatedBroker`**: Track `lastSettledDate`; if `onBar` advances to a new Shanghai date while `lastDateStr !== undefined && this.lastSettledDate !== lastDateStr`, auto-invoke `settleDayClose(lastDateStr)`. Callers invoking explicit `settleDayClose(prevDay)` set `lastSettledDate = prevDay` and experience zero double-settlement.
3. **Immutable `StrategySeriesImputer` Optimization**: Maintain an array + `head` offset (compacting when `head >= COMPACT_THRESHOLD`) and cache the frozen read slice (`cachedReadSnapshot`), invalidating solely on mutating calls (`hydrate`/`append`/`trim`/`reset`). Preserves `Object.freeze` & equality contracts while making `trim()` O(1) and repeated `read()` O(1).
4. **O(T) Memory in `StrategySimulationSession`**: Store per-frame `{ signalCount, latestSignals }` internally and materialize `signals` via `this.accumulatedSignals.slice(0, entry.signalCount)` on frame emission/navigation, avoiding `O(T^2)` signal array storage across 5k-bar replays.
5. **DAG-Safe Decision Flow Validation**: Enforce `seenIds.get(node.id)` equality: identical node object references reused as a shared DAG subtree are allowed, while two distinct objects sharing the same `id` fail closed with `DECISION_FLOW_RULE_INVALID`. Validate required node fields (`pluginId`, `exportAttributeKey`, `BRANCH.condition`, `TERMINAL.action`) uniformly.
6. **Non-Destructive Index Migration `039`**: Add `idx_strategy_alert_events_status_created (status, created_at)` via idempotent conditional SQL or standard `CREATE INDEX` in `039_add_strategy_alert_event_status_created_index.sql`, mirrored by `@Index('idx_strategy_alert_events_status_created', ['status', 'createdAt'])` on `StrategyAlertEvent`.
