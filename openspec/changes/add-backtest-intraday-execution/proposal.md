# Proposal: 回测盘中执行语义收口（多周期求值流上的撮合修正）

> 更正说明（2026-10-27 用户纠正后重梳）：本 change 初版假设"求值在日线、执行单独升粒度"，
> 该模型错误。实际架构：**求值流本身就是多周期合并流**（30m 求值 + 日线上下文，缠论在
> 30m 上确认买卖点、反映日线级别策略），执行层与求值层**复用同一条合并流**——策略层
> 发出信号后执行层才下单，天然有先后顺序。这一地基已由 `support-multi-period-evaluation`
> 交付（38/39，含 000001 30m 端到端冒烟）：其 task 3.2 明确 onBar/onSignal 仅对求值周期
> bar 触发，broker 已在 30m bar 上撮合。

## 1. 背景（真实残余缺口）

多周期地基之上，执行语义有三处真实问题：

1. **cooldown 强制冷却不合理（整体移除）**：硬止损后 arbiter 强制 `3 bars` 禁止再入场，
   且计数按 bar 递减——30m 求值下 3 bars = 1.5 小时（语义漂移）；更根本的，强制冷却
   会错过最终的开仓点（用户拍板 2026-10-27：**机制整体删除**，没啥用、以后再说，
   未见量化系统如此做）。
2. **首日涨跌停基准失真**：broker 的昨收自管理机制（日期跳变取前日最后一根 bar 收盘）
   在次日起正确，但**回放首日**回退 `meta?.preClose ?? bar.open`——executor 只注册了
   `{name}` 未传 `preClose` → 首日一字板判定用 bar.open 当昨收，失真。
3. **T+1 盘中边界缺显式回归锁**：broker 按 `frozenQuantity` 实现当日买入冻结、
   `settleDayClose` 日结算解锁——D 日盘中买入 → D 日后续 30m bar 禁卖的语义天然正确
   （粒度无关），但没有显式单测锁定，多周期重构时无护栏。

## 2. 目标

1. **移除强制冷却机制**：硬止损后不再阻塞再入场（`triggerCooldown`/计数器/构造参数
   全部删除）；
2. **首日昨收基准修正**：executor 从 prewarm/日线 context 注入回放起点昨日收盘
   （`registerSecurity` 已支持 `preClose`，只是没人传）；
3. **T+1 盘中边界回归锁**：显式单测锁定"D 日盘中买入 → D 日盘中禁卖 → 结算后 D+1 可卖"；
4. **盘中执行语义固化进 spec**：30m 撮合（确认 bar 下一根 30m bar 开盘成交）、盘中止损
   （30m low 刺破即成交）、涨跌停昨收基准、NAV 日基不变——大部分是对已交付行为的规格化。

## 3. 范围

### 本 change

- `libs/strategy/execution`：arbiter 冷却机制整体删除（构造参数/计数器/触发方法/调用点）；
- `apps/backtest`：executor 注册 security 时注入回放起点昨日收盘 preClose；
- 单测：cooldown 禁用、T+1 盘中边界、首日一字板判定；
- specs delta：盘中执行语义固化（`strategy-signal-backtesting`）。

### 非目标

- 30m 级别策略语义/插件编写（求值多周期本体 = `support-multi-period-evaluation`，已交付）；
- 盘中盯市 / 日内回撤指标（equity 仍日线采样，绩效口径不变）；
- 30m 数据缺失降级逻辑（**删除初版设计**——历史缺损归数据源修复/第三方补数，停牌在
  灌数前缺口处理已覆盖；合并流中缺 bar 即当日无交易机会，如实不造数）；
- 实时链路/实盘执行方式变更；1m 粒度；simulation 会话。

## 4. 影响面

| 仓库/层 | 影响 |
|---|---|
| `mist` libs/strategy/execution | arbiter 冷却默认值 |
| `mist` apps/backtest | executor 注册 preClose |
| 数据库 | **无变更**（不加列，用户拍板：成交粒度是引擎级统一行为，无需逐 run 记账） |
| API | 无变更 |

## 5. 风险

| 风险 | 处置 |
|---|---|
| 止损-再入场循环（连续绞肉） | 由策略信号与硬止损自身约束；如将来需要冷却由策略级插件表达 |
| prewarm 窗口无日线 bar 时 preClose 不可得 | 保持 broker 现有 `bar.open` 回退（首日边界，影响极小），不强行造数 |
| 既有 cooldown 单测失效 | 随行为变更同步改写（禁用语义的新断言） |
