# Proposal: 补齐缠论核心协同指标（吻态/斜率衰竭/动态中枢ZOI）与遗留无用指标剪枝

## 1. 背景与核心价值 (Context & Objectives)

Mist 量化交易系统在近期完成了缠论几何中枢生命周期引擎、因果撮合经纪商与牛熊战术策略的架构重构。在指标与特征工程排查中，暴露出以下核心痛点：

1. **缠论第 14 课“均线系统与吻态”缺乏确定性数学表达**：
   - 过去交易员理解的“飞吻、唇吻、湿吻”仅停留在主观形态直觉上，系统无法用机器语言区分“单边强势中继（飞吻）”与“中枢反复纠缠蓄能（湿吻）”，导致无法量化大牛股变盘爆发前夜的紧密粘合度。
2. **MACD 面积背驰计算存在严重滞后性**：
   - 现有动力学算子（`computeChanUnitForces`）必须等待整笔或整段完全封闭后才能统计红绿柱面积；但在 Next-Bar 因果撮合下，当一笔完全确立时价格往往已经大幅反弹，错失最佳买卖点先手。
   - 需要引入物理位移速度与斜率衰竭比（$v = |\Delta P| / \Delta t$），在单根 Bar 推进时提前 2~3 根 Bar 预警动能背驰。
3. **中枢相对震荡缺乏无量纲归一化量尺**：
   - 缠论核心操作原则包括“中枢内高抛低吸”与“第三类买卖点回抽确认”；
   - 系统此前缺乏无量纲中枢相对位置指标（ZOI），且中枢生命周期存在精细分层（笔中枢随内部振荡笔动态收窄，段中枢由前 3 段构件交集绝对锁定），亟需一个能自适应感知中枢动态区间的相对震荡算子。
4. **技术指标库中存在与缠论无关且未被消费的遗留资产**：
   - 全库检索证实：`ADX` 属于 100% 死代码（零控制器路由、零前端消费、零策略引用）；`RSI` 仅在后端存在一个孤立 HTTP 查询端点，前端 `mist-fe` 与策略树均为零引用。两个指标在纯正缠论体系中毫无地位，应安全剪枝退役。

---

## 2. 演进范围与定界 (Scope & Non-Goals)

### Scope
1. **三大缠论核心算子纯数学实现**（沉淀于 `libs/indicators/src/force/`）：
   - `kiss-states.ts`：均线吻态与缠绕度指标，显式判定 `FLYING`(飞吻)、`LIP`(唇吻)、`WET`(湿吻)，输出连续缠绕度分值；
   - `chan-slope.ts`：笔斜率与速度衰竭比指标，用初中物理速度模型比对前后同向笔推进速度，提前感知背驰；
   - `zhongshu-oscillation.ts`：动态中枢震荡相对指标（ZOI），自适应兼容笔中枢动态收窄与段中枢前 3 段锁定，归一化价格相对位置并量化三类买卖点回抽。
2. **双轨制与 Rust SIMD 工业底座契约**：
   - 严格基于 `nodejs-polars` SIMD 向量化表达式实现，严禁命令式循环；
   - 严格提供全时序 `compute*Series` 与尾部标量 `compute*Observation` 双轨制；
   - 坚守纯数学边界（零 I/O、零框架依赖、零 `process.env`，由 `indicators-boundary.guard.spec.ts` 守门）。
3. **安全剪枝退役遗留指标**：
   - 物理删除 `libs/indicators/src/classic/rsi.ts` 与 `adx.ts`；
   - 清理 `apps/mist/src/indicator/` 中无前端引用的遗留服务方法与路由端点。

### Non-Goals
- 不修改 `@app/chancore` 底层几何中枢状态机；
- 不在指标库中引入假突破决策树（留待后续独立规划）。
