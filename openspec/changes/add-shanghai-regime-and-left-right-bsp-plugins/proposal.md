# Proposal: 上证指数全局牛熊判断插件、主仓纯透传架构与全仓茅台资产清理

## 1. 业务背景与用户意图 (Background & User Intent)

根据用户最新拍板，重新审定并澄清以下五个核心维度：

1. **本地与线上数据源一致性**：
   - 本地数据源仅供本地 mock/单步推演使用，生产部署后无缝使用线上真实行情数据（MySQL `k` 表与 Redis 实时 candle）；
   - 策略内核 `StrategyEvaluationKernel` 统一消费标准 `StrategyBar` 序列。需要确保跨环境数据端口（`FactorContext.marketData`）标准同构，避免插件耦合本地环境或产生未来数据泄漏。

2. **上证指数全局牛熊判断（参考开源工业标准）**：
   - 目标明确锁定：**仅针对上证指数（000001.SH / 上证指数）** 进行牛熊周期判别；
   - 借鉴业内主流金工与开源量化框架（Dow Theory 经典年线系统、海通牛熊周期资产配置、Dual-MA 季线/年线斜率），以 Rust `nodejs-polars` SIMD 向量化计算为底座，严禁 JS 循环；
   - 结合多均线排列（MA60/MA250）、年线单调斜率（Slope）与价格突破，划分牛市（BULL）、熊市（BEAR）与震荡市（SIDEWAYS）。

3. **左右侧买卖点逻辑独立讨论（暂缓硬编码实现）**：
   - 用户明确指示：**旧注释与旧四象限战术全属作废**，不参考任何旧注释或遗留代码；
   - 左右买卖点的具体业务判定逻辑稍后与用户独立讨论确定，本阶段不在主仓或私有仓中擅自编写任何未经确认的买卖形态算法。

4. **主仓彻底回归“纯透传（Transparent Pass-Through）”架构**：
   - **开源与私有刚性隔离**：所有特定策略文本、徽标、战术文案必须 100% 收敛于私有仓库中，主仓绝对不包含任何专有买卖点文字或映射；
   - **私有插件定义输出**：由私有插件在 `FactorOpinion` / `evidence` 中直接产出最终的展示文本（`badgeText`、`displayText`、`reason` 等）；
   - **主仓改造为纯透传管道**：彻底重构主仓中现存的硬编码映射（如 `kernel-signal-mapper.ts` 的 `formatBadgeText`、`decision-pivot-evidence.ts` 的中文正则匹配、前端 `backtest-signal-visual.util.ts` 的 `CHAN_LABEL_MAP` 等），主仓只负责信道透传与图表挂载，绝不私自解析或篡改插件输出。

5. **全仓“茅台（Maotai / 600519）”存量内容、代码与注释全量清理**：
   - 本地模拟数据无茅台，全仓只保留上证指数（000001.SH / 000001）；
   - 彻底删除所有茅台快照夹具目录（`maotai-2024-2025`、`maotai-2024-2026`）、测试用例注册、页面默认回退代码及全仓相关注释，将黄金测试夹具与默认落地页平稳迁移为上证指数，并同步刷新 SHA-256 门禁指纹。

---

## 2. 方案目标 (Objectives)

1. **主仓纯透传化**：移除主仓与前端全链路上的买卖点文案硬编码，实现 `badgeText` 与展示元数据的 100% 无损透传；
2. **上证指数牛熊插件**：基于 Rust `nodejs-polars` 在主仓实现符合工业标准的 `ShanghaiRegimePlugin`，无缝支持本地 mock 与线上真实数据；
3. **私有插件通道就绪**：在私有仓规范化预留纯透传插件扩展骨架，具体左右买卖点逻辑等待用户进一步对齐；
4. **茅台彻底清理**：全仓移除所有茅台代码、夹具与注释，统一切换为上证指数。
